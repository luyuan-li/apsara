# 交互与窗口流程

## 窗口模式
| 模式 | 行为 |
|------|------|
| 普通 | 角色可拖；点击穿透可选（指针在角色外穿透到下层 App） |
| 锁定 | 关闭穿透，聊天/设置可点 |
| 纯角色 | 隐藏聊天面板，仅保留角色（可后续做） |

## 启动
1. 创建透明主窗 + 加载占位角色
2. 恢复上次位置（有则），否则靠屏幕右下偏上
3. 初始化 Agent（mock 或 `.env` 真模型）

## 对话
1. 用户输入 → 进入会话历史
2. Agent 调用 LLM（MVP：mock）
3. 若返回 tool_call 且 risk=`confirm` → 弹确认框，暂停工具执行
4. 用户确认/取消 → 工具结果回灌或取消提示
5. 助手气泡展示最终回复

## 拖拽
- 仅角色命中区拖动窗口（避免拖空白穿透区）
- 滚轮缩放角色（0.5x–2x），记住设置

## 退出
- 托盘「退出」或系统关闭；开发期可用窗口关闭退出
