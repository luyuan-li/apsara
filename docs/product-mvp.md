# Apsara MVP 产品说明

## 一句话
macOS 上透明置顶的「飞天」桌宠：能拖、能聊（先 mock）、能在确认后把文件丢进废纸篓。

## 目标用户
愿意自己编译/跑开发版的开发者；中文为主，仓库对外英文友好。

## MVP 必做（验收清单）
- [ ] `pnpm install` 后能按 README 启动桌面窗口（`tauri dev` 或等价命令）
- [ ] 窗口透明、无边框、始终置顶；角色区域可拖动
- [ ] 占位角色可见（SVG/PNG/CSS 即可，不要求 Live2D）
- [ ] 聊天气泡 + 输入框；走 `@apsara/mock-llm` 回声
- [ ] 「锁定」可开关点击穿透（或 MVP 先不做穿透，但文档写明）
- [ ] `trash_path`：确认对话框 → 移到废纸篓（仅白名单路径）
- [ ] 托盘或明确退出方式（Cmd+Q / 托盘退出至少一种）

## MVP 不做
- Live2D 正式模型与口型
- 语音 ASR/TTS
- 任意 Shell / 键鼠注入
- 多宠物联机、长期记忆、自动更新

## 成功体验（主观）
打开后桌面上有一个安静的小角色；打字有回复；让它扔掉测试文件时会先问你，点确认后文件出现在废纸篓。
